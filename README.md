How to Use

Enter any word, name, or phrase into the calculator.

TOTAL: The sum of all letter values.

REDUCED: The total reduced to a single digit.

Example: FREEMASON

F(6) + R(9) + E(5) + E(5) + M(4) + A(1) + S(1) + O(6) + N(5)

TOTAL = 42 | REDUCED = 6

Now experiment with other words and phrases. Compare numerical values, discover patterns, and draw your own conclusions.
